# StudyDock artwork

The app icon was generated with the built-in image-generation tool, then resized into the Chrome PNG and Windows ICO sizes using `tools/build_icons.py`. macOS ICNS is generated during packaging. No external image service is called by the app.

Source: `extension/icons/studydock.png`. Interface symbols remain Google Material Design icons under the bundled Apache 2.0 license.

Generation prompt:

> Create one production app icon for StudyDock, a calm study tool for practice exam review and personal question notes. No lettering, text, words, labels, mockups or surrounding objects. A compact distinctive geometric open notebook with a folded bookmark forming a subtle docking notch, centered on one rounded-square deep slate-blue app tile, pale cool-blue notebook pages and a single muted seafoam bookmark accent. Material Design inspired, flat precise shapes, exceptionally legible silhouette at 16–32 pixels, generous clean spacing, no decorative tiny lines, no gradients or 3D effects, no neon, no sparkles. Icon fills about 86% of square canvas; outside the rounded-square tile genuinely transparent. Square high-resolution PNG, front view. This is a new app brand icon, not a diagram.
